# NumPy Demos

Small demo scripts for NumPy-based benchmarking, random distribution sampling, and loan payment calculations.

## Prerequisites

Install dependencies in this folder:

```bash
pip install -r requirements.txt
```

Dependencies listed in [requirements.txt](requirements.txt):

- numpy
- jupyter
- handcalcs

Some scripts also import optional libraries:

- pydantic
- typer
- rich
- numpy_financial
- matplotlib (only needed for plotting in `normal_dist.py`)

## Quick Start

Run from this folder so relative paths work:

```bash
cd numpy
python3 arr.py
python3 timeit_sum.py
python3 normal_dist.py --dump
python3 ndist.py --conf dist.json
python3 np_pmt.py
python3 pmt_json.py pmt.json
```

For notebooks:

```bash
jupyter notebook
```

## Script Summary

- [arr.py](arr.py)
  - Async benchmark that compares Python `sum()` vs `numpy.sum()` on a very large random array.
  - Uses `ThreadPoolExecutor`, timeout control, and rich console output.
  - Note: `MAXCNT = 500_000_000` can require a large amount of memory.

- [sum_timeit.py](sum_timeit.py)
  - Timeit benchmark of a manual Python loop sum vs `numpy.sum()`.
  - Uses fixed defaults: array size 10,000 and 10,000 benchmark runs.

- [timeit_sum.py](timeit_sum.py)
  - Class-based benchmark that repeatedly calls built-in `sum` and `numpy.sum`.
  - Prints wall-clock duration for each approach.

- [normal_dist.py](normal_dist.py)
  - Generates normal-distribution data with configurable `mu`, `sigma`, and `size`.
  - Optional features:
    - `--dump` writes integer-converted values to `normal_dist.log`
    - `--draw` plots histogram + Gaussian curve (requires matplotlib)

- [ndist.py](ndist.py)
  - Typer CLI that reads distribution parameters from [dist.json](dist.json) and generates data with NumPy RNG.
  - Prints the resulting sample values to console.

- [vald_gauss.py](vald_gauss.py)
  - Repeats random normal-data generation and validates whether sampled mean/stdev stay near target thresholds.
  - Prints size, resulting mean/stdev, and observed min/max.

- [np_pmt.py](np_pmt.py)
  - Loan payment demo using `numpy_financial.pmt`.
  - Supports CLI arguments (rate, periods, present value) via Typer.

- [pmt_json.py](pmt_json.py)
  - Loan payment calculation from JSON config input.
  - Reads defaults from [pmt.json](pmt.json).

## Data Files

- [dist.json](dist.json): default parameters for normal distribution (`mu`, `sigma`, `size`).
- [pmt.json](pmt.json): default loan parameters (`rate`, `nper`, `pv`).
- [normal_dist.log](normal_dist.log): generated by `normal_dist.py --dump`.
