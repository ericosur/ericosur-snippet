# README

using python script numeric simulation to solve some problems
(maybe brute force)

## Layout

- Reusable or topic scripts stay at this level.
- Contest-style scripts are grouped in `contest/`:
	- `contest/date_coded/`: files like `d240318-q11.py`
	- `contest/year_page/`: files like `y24p25q3.py`
	- `contest/page_question/`: files like `p43-q4.py`
	- `contest/scratch/`: quick scratch files like `qq13.py`
