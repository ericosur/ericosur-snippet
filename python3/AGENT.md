# Agent Instructions

This document provides project-specific guidelines and environment setup instructions for AI coding agents working in this workspace.

## Environment Setup & Python Version

> [!IMPORTANT]
> If the active Python version in the shell is the same as the system-wide Python version (e.g., Python 3.12.x), you **must** activate the virtual environment first before executing any Python code or scripts.

### Activation Steps:
1. Navigate to the virtual environment directory: `~/venv/py314/bin/`
2. Activate the virtual environment:
   ```bash
   source ~/venv/py314/bin/activate
   ```
3. Verify that the Python version is updated to Python 3.14.x:
   ```bash
   python --version
   ```
